# בית לחמוס · React

גרסת React ב־JavaScript עם Vite, הכוללת את כל תוכן האתר והמדיה.

## דרישות
Node.js 22.12 ומעלה, או Node.js 20.19 ומעלה.

## התקנה והרצה
```bash
npm install
npm run dev
```
פתחו את הכתובת שמופיעה בטרמינל.

## יצירת גרסה להפצה
```bash
npm run build
npm run preview
```
הקבצים המוכנים לאירוח נמצאים בתיקיית dist. אפשר לארח אותם בכל שרת סטטי.

## מבנה
- src/App.jsx: התנהגות האפליקציה, חלונות, תפריט וסרטון.
- src/Page.jsx: מבנה ותוכן העמוד ב־JSX.
- src/content.js: תוכן הסיפורים המלאים, הפרופילים וקישור PayPal.
- src/styles.css: עיצוב ותצוגת מובייל.
- public/assets: תמונות וסרטון.

המעבר ל־PayPal מחייב גילוי סאטירה ואישור מפורש. הסכום והמטבע מוזנים ב־PayPal; אין אימות תשלום באתר. אין מפתחות סודיים בפרויקט.

צילום וסרטון: Pexels. תמונות סיפורי ההצלה סופקו על ידי יוצר האתר. Heebo נטען דרך Google Fonts, עם גופן חלופי ללא חיבור לאינטרנט.

נוצר על ידי שון דוד.
