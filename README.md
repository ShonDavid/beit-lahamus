# בית לחמוס · React

גרסת React ב־JavaScript עם Vite, הכוללת את כל תוכן האתר והמדיה.

## דרישות
Node.js 22.12 ומעלה, או Node.js 20.19 ומעלה.

## התקנה והרצה
```bash
npm install
npm run dev
```
פתחו את הכתובת שמופיעה בטרמינל.

## יצירת גרסה להפצה
```bash
npm run build
npm run preview
```
הקבצים המוכנים לאירוח נמצאים בתיקיית dist. אפשר לארח אותם בכל שרת סטטי.

## מבנה
- src/App.jsx: התנהגות האפליקציה, חלונות, תפריט וסרטון.
- src/Page.jsx: מבנה ותוכן העמוד ב־JSX.
- src/content.js: תוכן הסיפורים המלאים, הפרופילים וקישור PayPal.
- src/styles.css: עיצוב ותצוגת מובייל.
- public/assets: תמונות וסרטון.

## חמוס היום

מדור החדשות הועבר מהאתר הקיים, עם עשר כתבות מלאות ותמונות השער שלהן. דף הבית מציג שלוש כתבות; `/blog` מציג כתבה מובילה וכל עשר הכתבות. לכל כתבה כתובת קבועה תחת `/blog/:slug`, קישורים לכתבות נוספות וכפתורי תמיכה המשתמשים בחלון התשלום הקיים.

- src/articles.json: תוכן, קטגוריות, כתובות, תמונות, תאריכים וזמני קריאה.
- src/Blog.jsx ו־src/blog.css: עמודי המדור ועיצוב המגזין.
- src/SiteLayout.jsx: כותרת ותחתי העמוד המשותפות.
- src/blogMetadata.js: כותרות SEO, כתובות קנוניות ותגיות שיתוף.
- scripts/build.mjs: יצירת HTML מלא לדף הבית, למדור ולכל כתבה, כדי שתוכן ותגיות שיתוף יהיו זמינים גם לפני הרצת JavaScript. קובצי Vite נטענים מכתובות מוחלטות כדי לאפשר פתיחה ישירה ורענון של כתבות.

לאחר `npm run build`, אפשר לבדוק את התוכן, הכרטיסיות, התמונות, הקישורים ותגיות השיתוף:

```bash
node scripts/check-blog.mjs
```

סרטון המסיבה עדיין אינו זמין; מוצגת תמונה עם הכיתוב ״הסרטון המלא בקרוב״.

המעבר ל־PayPal מחייב גילוי סאטירה ואישור מפורש. הסכום והמטבע מוזנים ב־PayPal; אין אימות תשלום באתר. אין מפתחות סודיים בפרויקט.

צילום וסרטון: Pexels. תמונות סיפורי ההצלה סופקו על ידי יוצר האתר. Heebo נטען דרך Google Fonts, עם גופן חלופי ללא חיבור לאינטרנט.

נוצר על ידי שון דוד.

ההורוסקופ החודשי זמין ב־`/blog/horoscope`, עם בחירת מזל, התאמה לתאריך לידה ושיתוף התחזית. קישורים אליו מופיעים בדף הבית ובמדור החדשות.
